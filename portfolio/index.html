01Multi-agent systemAltrosyn · 2026

TalentOps

An AI recruitment system: five specialised sub-agents orchestrated with LangGraph, with a live voice interviewer on Google Meet.

  • Native multimodal voice. Built on the Gemini Live API instead of chained STT/TTS, for sub-300 ms audio latency; Vexa handles Meet transport.
  • Voice Ownership Rule. A session broker ensures the Manager and Interviewer agents never cross-speak or share voice context.
  • Extractive Evaluation. Every competency score must cite a validated verbatim transcript quote — no quote, no score.
  • Fairness & Bias Lens. A k-anonymised heatmap correlates candidate cohorts with question difficulty.

02NLP · EnsemblePersonal project

LexiGuard

A dual-brain legal clause detector that flags predatory clauses by fusing two very different models.

  • Lexical Sniper. TF-IDF + Gradient Boosting catches the surface patterns of risky language.
  • Semantic Brain. Legal-BERT reads for meaning when the wording is unusual.
  • Maximum-Threat Logic Gate. Fuses both brains at a 45% threshold, reaching 88% recall on clause detection.
  • Grounded explanations. Two React frontends on the Anthropic API use anti-hallucination chunking to stay tied to the source clause.

88%recall

03Agentic pipeline · RAGPersonal project

Vorkos

An agentic job aggregator — a full discovery-to-ranking pipeline that automates the manual job search right up to the apply step.

  • Live discovery. Tavily scrapes openings in real time; the Groq API handles intelligent filtering.
  • Fit scoring, not keywords. RAG over ChromaDB scores every role against the candidate's actual résumé profile.

04Data engineeringPersonal project

Data Vacuum

Niche datasets simply don't exist on public repositories — so this pipeline collects and validates custom training data from scratch.

  • Targeted collection. The Groq API writes search prompts, Tavily scrapes the raw web content, and an NLP layer cleans it into a training-ready format.
  • ML relevance gate. A classification model admits only high-quality, on-topic samples, keeping each dataset tightly scoped.
  • Zero hand-labelling. End-to-end automated, with no manual curation.
